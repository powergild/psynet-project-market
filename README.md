# 데이터 박스

축을 교차시키면 AI가 셀을 채우는, 내 관점으로 만드는 스포츠 데이터 격자.

> **레포 이름이 서비스와 다릅니다.** `psynet-project-market`은 이 레포가 전에 담고 있던
> 사내 프로젝트 매칭 서비스의 이름입니다. 2026-10-20에 서비스를 **데이터 박스**로 바꿨고,
> 레포·도메인·DB는 그대로 물려받았습니다. 자세한 내용은 [CLAUDE.md](CLAUDE.md)의 「피벗 이력」.

## 성격 — 개인 취미 프로젝트

개인이 취미로 만들고 운영하는 **비상업 프로젝트**입니다.

- 상품이나 서비스를 **판매하지 않습니다.** 결제 수단(PG) 연동이 없고, 결제·구독·유료 기능이 없습니다.
- **광고를 싣지 않습니다.** 광고 네트워크, 트래킹, 제휴 링크가 없습니다.
- **수익이 없습니다.** 이 사이트로 들어오는 돈이 없습니다.
- 화면에 보이는 "가격"은 전부 **게임 안의 가상 수치**입니다(`lib/pieces.ts`의 조각 가격). 현금과 교환되지 않습니다.

결제·광고·유료 기능을 붙이려면 `app/layout.tsx`의 비상업 고지와 이 문단도 함께 고쳐야 합니다.
(이 성격은 원래 Vercel Hobby의 비상업 조건 때문에 명시한 것입니다. 지금은 자체 호스팅이라
플랫폼 제약은 없어졌지만, 취미 프로젝트라는 성격 자체는 그대로 둡니다.)

## 개발

```bash
npm install
npm run dev
```
